# A.L.P.H.A Cloud Edition

Open the [cloud assistant](https://nishanth6609.github.io/alpha-6/cloud/) in a browser. Read [SETUP.md](SETUP.md) for provider profile and API key instructions.

This edition supports multiple visitor-owned API key profiles for OpenAI-compatible chat APIs, including custom endpoints. Keys stay in the current browser tab's session storage and are sent directly to the selected provider. It is separate from the Ollama-based assistant at the site root; no shared key is stored in this repository.
