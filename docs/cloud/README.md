# A.L.P.H.A Cloud Edition

Open the [cloud assistant](https://nishanth6609.github.io/alpha-6/cloud/) in a browser. Read [SETUP.md](SETUP.md) to connect your OpenRouter key.

This edition uses one visitor-owned OpenRouter API key and automatically selects the `openrouter/free` router. The key stays in the current browser tab's session storage and is sent directly to OpenRouter. It is separate from the Ollama-based assistant at the site root; no shared key is stored in this repository.
